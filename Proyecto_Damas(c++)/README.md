# Damas-c-
Materia: Estructura de datos
Proyecto: Damas en C++ para practicar uso de array (1D, 2D y 3D) y búsquedas

Requerimientos y limitaciones establecidas:
- Tablero 8x8
- Para 2 jugadores
- Comienza el jugador de las fichas claras.
- Las fichas normales se mueven en diagonal y sólo hacia delante.
- Está obligado a comer si tiene la posibilidad de hacerlo.
- Debe comer fichas seguidas si puede hacerlo.
- Cuando una ficha normal cruza el tablero se corona como Dama.
- La Dama puede moverse hacia delante y hacia atrás en diagonal.
- El juego acaba cuando uno de los dos se acaba las fichas del otro, lo acorrala o llegan a la conclusión de acabar.
